### Day1：模拟基础

#### 一、输入输出

- 万能头：#include<bits/stdc++.h>

- cin与cout作为输入输出函数的缺点是**速度较慢**，所以需要用指令进行加速（关同步），关同步后就不要同时使用cin/cout和scanf/printf

```c++
#include<bits/stdc++.h>

using namespace std;

int main()
{
    //关同步指令如下：
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    //关同步指令如上
    int x,y;
    cin >> x >> y;
    cout << x << endl << y;
    return 0;
}
```

#### 二、多组输入

​	我们在输入输出时要遵守题目的输入输出格式规范，常见的有以下几种输入方式

##### 1）有条件的多组输入

![image-20260311222851486](C:\Users\Duuuzx\AppData\Roaming\Typora\typora-user-images\image-20260311222851486.png)

```c++
#include<bits/stdc++/h>
using namespace std;
int main()
{
	int n,num_even = 0,sum_odd=0;
    while(cin >> n)
    {
        if(n==0) break;
        else
        {
            if(n%2 == 0) num_even++;
            else sum_odd += n;
        }
    }
    cout << num_even << endl << sum_odd;
}
```
