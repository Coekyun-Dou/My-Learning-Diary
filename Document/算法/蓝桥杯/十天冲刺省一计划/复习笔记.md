##### 1、`cin/cout`与`scanf/printf`

    ios::sync_with_stdio(0);

##### 2、多组输入

​	题目会对输入输出的格式进行规范，有以下几种常见的；

- 有条件的多组输入（看到xxx条件就停止输入之类的）
  - [题目详情 - 奇偶统计 - DashOJ](https://dashoj.com/p/8)：要求不断输入最后一个数字是0
  - 就是进行循环，当数字等于0的时候break就行；while(cin>>n) if(n==0) break;
- 无条件的多组输入
  - [题目详情 - 奇偶统计改 - DashOJ](https://dashoj.com/p/9)：删去了以0为循环结束的条件
  - 利用cin>>原本的特写（直接不用判断，使用ctrl+z和回车作为结束标志）
  - 也可以用回车符号作为判断：while(cin>>n) if(n=='\n') break;
- `getline`读入带空格的字符
  - [题目详情 - 作文标题 - DashOJ](https://dashoj.com/p/10)：读入带空格的字符串，然后统计出不带空格的字符数
  - cin和scanf无法读入空格（会当作结束标志），需要用getline来进行读入
  - string str ; getline(cin,str);
  - 获取这个字符串的长度 i = str.length();
- 综合题目
  - [题目详情 - 作文标题改 - DashOJ](https://dashoj.com/p/12)：要计算一个含有大小写字母、空格、换行符的字符串的字符数；
  - 这道题比较奇怪的是他的输入格式：两行：第一行是==字符串的长度（会包含空格）==；第二行字符串s；
  - 所以这道题不同是不能直接用cin输入数据，因为这样的话包含空格的第一行数据会读入失败，所以要用getline读入字符串，然后用stoi函数将字符串中的数字提取出来；
  - getline(cin,t); getline(cin,str); int n = stoi(t);
  - 如果要将数字转成字符串，可以使用`to_string()`指令：string t;int n; cin>>n; t=to_string(n);
