##### 1、映射map

> 提供了一个映射的键值对

​	`map<key,value>`提供一对一的数据处理能力，由于这个特性，它完成有可 能在我们处理一对一数据的时候，在编程上提供快速通道。 map  中的第一 个值称为关键字 (key) ，每个关键字只能在 map  中出现一次，第二个称为该 关键字的值 (value) ，可以重复。

- 创建操作

```c++
map<string,int>mp //mp是别名
```

- 插入操作

```c++
mp.insert(make_pair("zhs",18));//如果原先存在该key，就无法插入和覆盖
mp["zhs"]==18 //如果原先不存在key就创建一个，如果原先存在就覆盖掉原来的value
```

- 删除操作

```c++
mp.erase(key);//删除值为key的元素
mp.clear();//清空集合
```

- 求大小

```c++
int siz = mp.size();//求集合大小
bool flag = mp.empty();      // 集合判空
```

#### 二、递归

​	递归就是函数调用自己本身；

<img align='left' src="C:\Users\Duuuzx\AppData\Roaming\Typora\typora-user-images\image-20260404215300529.png" alt="image-20260404215300529" style="zoom:90%;" />

```c++
int func(传入条件)
{	
    if(终止条件)return 最小问题解;
    return func(缩小规模);
}

public int sum(int n)
{
    if(n <= 1) //终止条件
    {
        return 1;
    }
    return sum(n-1)+n;  //调用自身
}
```

##### 1、递归的特点

- 自身调用：原问题可以分解为子问题，子问题和原问题的求解方法是一致的，可以调用同一个函数
- 终止条件：必须有一个终止条件，不能无限循环第地调用

##### 2、递归解题思路

- 还是抓住递归的特点，就是一定要有终止的条件，所以用递归思路去解决问题的时候，需要寻找递归终止条件是什么，比如阶乘问题，当n=1时就不用往下递归了；

```c++
//n的阶乘（n大于0的自然数）
int factorial(int n)
{
	if(n==1)
	{
		return 1;
	}
	return n*factorial(n-1);
}
```
