### 01 - 假设修正法

​	初学编程，容易对if....else嵌套情有独钟，经常写出很不容易读懂的程序。为了纠偏，我们可以尽量故意训练自己：

- 不用if嵌套
- 不用else

>  程序的复杂度来源就是：**分支**和**循环**

​	**假设修正法是可以避免用else，嵌套的一种思路**：

​	不是一次性给事务定性。而是，先初始定性，以后再拨乱反正...

【例】学生成绩评级

​	输入学生分数（百分制），比如85，按分数评级：

​	>90 优秀 >80 良好 >70 中等

> 这样的程序好写、但是不好读。会带着超级多层的嵌套

而且，如果有大量的数据要处理，这个流程不优化，不及格分数太多的话，运行可能会超时...

减少嵌套层数，可以：

- 提高运行效率
- 降低逻辑复杂度，减少程序员心智负担，增加可读性

也可以用假设修正法来做：

> 所有假设修正法，就是先一棍子打死：假设所有都不及格，再一个个判断、改正他的等级

```c++
#include<bits/stdc++.h>
using namespace std;
int main()
{
    int a;
    cin >> a;
    string s = "不及格";//假设所有人都是不及格，把串的数值复制到数组
    if(a >= 60) s="及格";
    if(a >= 70) s="中等";
    if(a >= 80) s="良好";
    if(a >= 90) s="优秀";
    cout << s;
    return 0;
}
```
