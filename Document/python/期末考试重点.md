### 第一章：Python开发环境搭建雨使用

> 就考察两个东西：一个是pip，一个是库导入

#### 一、扩展库的安装

```
pip download // 下载扩展库
pip freeze[reqirements.txt] //列出已经安装的模块到requirements中
pip list //列出已安装的所有模块
pip install 安装
pip install xxx.whl //通过whl文件离线安装
```

#### 二、扩展库的导入与使用

- import 包名/模块名 [as 别名]

```python
import numpy as np
```

- from 包名/模块名 import 对象名 [as别名]

```python
from math import sin as f
```

- from 模块名 import *

```python
from math import *  #一下导入模块中的所有对象
```

#### 三、`_name_`属性的使用

```python
if _name_ == '_main_':
    ... #此处是要执行的语句        
```

##### 1）常量与变量

- 使用前无需声明变量以及类型
- python中变量**不直接存储值，而是存储值的内存地址或引用**，如果不同变量赋值为相同值，这个值在内存中只有一份，**多个变量会同时指向一块内存地址**。
- 因为python属于**强类型编程语言**python不仅变量的值是可以变化的，类型也是可以随时变化的

- python的命名规则
  - 必须以字母、汉字或下划线开头
  - 不能包含空格或中英文标点符号
  - 不能使用关键字，不建议使用系统内置模块名
  - 对英文字母大小写敏感

##### 2）数字

- Python支持**任意大**的数字，具体多大受内存大小限制

- 由于精度问题，**要尽量避免在实数之间直接进行相等性测试**

  - ```python
    0.4 - 0.3 == 0.1 #结果是False
    ```

  - 如何解决这个问题？使用**decimal类型**、或者用math.isclose函数

  - ```python
    from decimal import Decimal
    a = Decimal('0.1')
    b = Decimal('0.2')
    a + b == 0.3
    ```

##### 3）字符串与字节串

- Python中只有字符串没有字符的概念，**单个字符也是字符串**，使用**单引号、双引号、三单引号、三双引号**作为定界符来表示字符串，**不同的定界符之间可以互相嵌套**
- 可以用 + 号连接字符串

#### 二、运算符与表达式

##### 1）算术运算符

- ==+运算符==除了用于算术加法以外，还可以用于**列表、元组、字符串的连接**，但不支持不同类型的对象之间的相加或连接

- ==*运算符==除了表示算术乘法，还可**用于列表、元组、字符串这几个序列类型与整数的乘法**，表示序列元素的重复，生成新的序列对象。**字典和集合不支持与整数的相乘**，因为其中的元素是不允许重复的。

  - ```python
    print([1,2,3] * 3)
    #结果是[1,2,3,1,2,3,1,2,3]
    ```

- ==**运算符/和//**==在python中分别表示算术除法和<u>算术求整熵</u>（就是整除，去掉余数）

  - ```python
    3/2 #除法、结果是1.5
    15//4  #算术求整数熵，结果是3
    ```

- **==%运算符==**可以用于整数或实数的求余数运算，还可以用于字符串格式化，但是这种用法并不推荐。

  - ```python
    '%c,%d,%f,%s' %(65,65,65,65)
    #分别把65格式化为字符，整数，实数，和字符串
    ```

- ==**运算符==可以表示幂乘，例如3**2 == 9

##### 2）成员测试运算符in与同一性测试运算符is

- **成员测试==运算符in==**用于成员测试，即测试一个对象是否为另一个对象的元素

- 同一性测试==运算符is==，用来测试两个对象是否是同一个，如果是则返回true，否则返回false。

```python
#注意！
x = [1,2,3]
y = [1,2,3]
x is y
#结果是false 因为上面形式创建的x和y不是同一个列表对象
```

##### 5）补充说明

- Python还有赋值分隔符 = 和 +=、-=、*=、/=、//=、**= 、 |=、^=等大量符合赋值分隔符。例如x+=3 等价于 x = x+3

- Python**不支持++和--运算符**，虽然在形式上有时候似乎可以这样用，但实际上是另外的函数；++1= 1 、--1=1（这里的 + 和 - 表示的是符号）

- ==**：=**海象运算符==，可以在选择结构、循环结构的条件表达式或者函数调用中直接创建变量并为变量赋值，使得代码更加简洁。这个运算符**不能在普通语句中直接使用，需要在外面加一对圆括号**

  - ```python
    #不使用海象运算符
    n = len(a_list)
    while n > 0:
        #do something(循环体)
        n -= 1
        
    #使用海象运算符
    while(n := len(a_list)) > 0:
        #do something(循环体)
    ```
