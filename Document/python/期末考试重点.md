#### 一、列表

​	包含若干元素、连续内存空间；能够自动管理内存，比如在中间删去一个元素，那么后面的元素会自动补上来，保证相邻元素间没有缝隙。

​	列表间的元素用逗号隔开，同一个列表中元素的数据类型可以不同。

##### 1）列表的创建与删除

==**创建**==

- 直接创建

```python
a_list = ['a','b']
```

- 用list函数把其他可迭代对象转换为列表

```python
list(range(1,10,2)) #把range对象转换为列表
#结果为[1,3,5,7,9]
```

==删除==

- 使用del命令

```python
x = [1,2,3]
del x
```

##### 2）列表元素访问

- 可以使用下标来访问，**正序从0开始表示第一个元素，倒序从-1开始表示最后一个元素**，以此类推

##### 3）常用方法

- 插入操作

  - `append()`：在列表末尾追加一个元素

  - `insert(a,b)`：在a位置，插入元素b

  - `extend()`：用于将一个可迭代对象插入到列表尾部

- 删除操作
  - `pop()`：删除最后一个位置的元素
  - `remove(2)`：删除列表中第一个值为2的元素
  - `clear()`：清空列表中的所有元素
- 统计操作
  - `count(2)`：返回列表中出现2的次数
  - `index(2)`：返回元素2在列表中首次出现的位置
- 排序
  - `x.sort()`：按照默认规则排序
  - `x.reverse()`：把所有元素翻转或逆序

- 复制

  - 浅复制`copy()`：例如`y = x.copy()`，但是这样的话修改x的值会顺便改变y
  - 深复制`deepcopy()`：这样x和y完全独立，但是要先`import copy`

- 运算符

  - +表示连接左右的元素
  - 和整数相乘，表示重复序列
  - in 看看有没有包含某个元素
  - is 看相不相同

- 切片操作（用一个中括号表示）

  - 第一个数字表示切片开始位置，第二个数字表示切片截止位置，第三个数字表示切片步长

  - 切片开始坐标是从0开始，结束的坐标是从1开始（对于结束来说，列表的第一个元素坐标为1）

  - ```python
    aList = [3,4,5,6,7,9,11,13,15,17]

    aList[1::2] #从1开始，隔一个取一个获取奇数位置的元素
    >>> 4,6,9,13,17
    ```

  - 还可以用切片在列表任意位置插入新的元素

  - ```python
    aList[len(aList):] = [9] #在列表尾部增加元素
    aList[:0] = [1,2] #在列表头部插入多个元素
    aList[3:3] = [4] #在列表中间位置插入元素
    ```

​	放在一对圆括号里，元素之间用逗号隔开，**如果元组只有一个元素则必须在最后加一个逗号**，（真正创建元组的是逗号，圆括号只是辅助）定义后的**元组中元素的数量和引用不允许改变**，这是元组与列表最本质的区别。

##### 1）元组的创建与访问

```python

#### 三、字典

​	字典是一个包含若干**键值对**的**无序可变容器对象**，字典中**每个元素用冒号分隔开“键”与“值”两部分**（键与值用冒号隔开，键值对与键值对用逗号隔开），最后所有的元素放在一对大括号里面。

​	字典中的**键得是不可变的数据**，如整数、实数、复数、字符串等，不能用列表、集合等其他可变类型对象。**字典中的键不允许重复，但是值允许**

##### 1）字典的创建与删除

```python
data = {'国家':['富强','民主','文明','和谐'],
		'社会':['自由','平等','公正','法治'],
		'公民':['爱国','敬业','诚信','友善']}
```

##### 2）字典元素的访问

​	通过输入字典的键，来访问对应的值。

```python
aDict['aget'] #会输出age键对应的值
```

##### 3）字典元素的添加、修改与删除

- 添加与修改

  - 当指定的键存在时，表示修改该键对应的值；

  - 当指定的键不存在时，表示添加一个新的“键、值”，也就是添加一个新的元素。

  - ```python
    aDict['age'] = 39 #修改age对应的值为39
    aDict['address'] = GDOU #没有address这个键，相当于添加新元素
    ```

  - `	update()`方法用于把另一个字典的键值对添加到当前字典对象中，如果存在相同的键，则以update更新的为准。

- 删除操作
  - 使用del命令，例如：`del aDict['age']`删除字典中age这个键所在的元素
  - `pop()`：删除指定的“键”，返回对应的“值”
  - `popitem()`：删除最后一个元素，并返回

#### 四、集合

​	集合属于无序可变容器对象，由一对大括号围住，元素之间使用逗号分隔，同一个集合内的每个元素都是唯一的，**元素之间不可以重复**。集合中只能包括不可变类型的数据，不可以包括列表、字典、集合等可变类型的数据。

##### 1）集合的创建与删除

- 直接创建

  - ```py
    a = {1,2,3}
    ```

- 用set函数将列表、元组等转成集合，并自动去除重复元素。

  - ```python
    list = [0,1,1,2,3,4,3,3,4]
    b_set = ste(list) #结果是[0,1,2,3,4]
    ```

##### 2）集合元素的增加与删除

- 增加：`add()`方法：直接在集合内添加元素，如果元素已存在则忽略该操作。
- 修改：`update()`：用于合并另外一个集合中的元素到当前集合中，并自动去除重复元素
- 删除：
  - `pop()`随机删除集合中一个元素，集合如果为空抛出异常
  - `remove()`删除集合中的指定元素，如果不存在则抛出异常
  - `discard()`用于从集合中删除一个特定元素，如果不在则忽略该操作
  - `clear()`清空集合删除所有元素

##### 3）集合的操作与运算

```py
a_set | b_set  # 并集
a_set.union(b_set) #并集
a_set & b_set  #交集
a_set.intersection(b_set) #交集
a_set.difference(b_set) #差集

### 第七章：字符串

#### 一、核心概念

##### 1）字符串的定义与特性

- **不可变性**：字符串属于**不可变有序容器**。这意味着一旦创建，就**不能**直接修改其中的字符（不能赋值 `s[0] = 'a'`）。所有的修改操作（如 replace, strip）实际上都是返回一个新的字符串对象，原字符串不变 。

  - ```python
    s = "python"
    s.upper()       # 这里返回了 'PYTHON'，但没有赋值给变量
    print(s)        # 输出仍然是 'python'，很多同学这里会丢分
    ```

- **定界符**：单引号 `'`、双引号 `"`、三引号 `'''` 或 `"""` 都可以，且可以互相嵌套

- **序列操作**：支持通用的序列操作，如索引、切片、计算长度 `len()`、成员测试 `in` 。

##### 2）字符串编码

- 长度计算：`len()` 统计的是**字符个数**，不是字节数。

  - 例子：`len('中国')` 的结果是 **2**，不是 4 也不是 6

- 编码转换：

  - **str $\to$ bytes**：使用 `.encode()`（解码）

  - **bytes $\to$ str**：使用 `.decode()`（编码）

  - **常见错误**：用 `utf-8` 编码的字节串，如果用 `gbk` （专属中文的）解码会报错（`UnicodeDecodeError`）或乱码 。

  - ```python
    # 考试中可能会问你这段代码的结果：
    s = '测试'
    b = s.encode('utf-8')  # 编码成字节
    # print(b.decode('gbk')) # 报错！因为编码格式不匹配
    ```

##### 3）转义字符与原始字符串

- **常用转义**：`\n` (换行), `\t` (制表符), `\'` (单引号), `\"` (双引号) 。
- **原始字符串 (r/R)**：在引号前加 `r`，让转义字符失效，常用于**文件路径**。
  - 普通写法：`'C:\\Windows\\notepad.exe'` (需要双斜杠) 。
  - 原始写法：`r'C:\Windows\notepad.exe'` (所见即所得) 。

##### 2）`%` 运算符（旧式，类似 C 语言）

##### 3）`str.format()` 方法（经典，推荐掌握）

- **语法**：使用 `{}` 作为占位符，后面跟 `.format()`。

#### 三、核心操作方法

##### 1） `split()` 分割

**陷阱 1：不传参数 vs 传空格**

- `s.split()`（不传参）：**最智能**。它会把空格、换行(`\n`)、制表符(`\t`)全部当成分隔符，而且**会自动删除空字符串** 。
- `s.split(' ')`（指定空格）：**很死板**。只认空格，如果两个词之间有3个空格，它会切出2个空字符串 `''` 

```python
s = 'a   b'
s.split()    -> ['a', 'b']          # 推荐
s.split(' ') -> ['a', '', '', 'b']  # 注意中间的空串
```

**陷阱 2：`maxsplit` 参数**

- 指定最大分割次数，剩下的内容会作为一个整体保留 。

##### 2）`join()` 连接

- **用法**：`'连接符'.join(可迭代对象)`
- **注意**：列表里的元素**必须全部是字符串**，如果有数字会报错 。

```python
li = ['apple', 'pear']
','.join(li)  -> 'apple,pear' [cite: 448]
```

##### 3）`strip()` 去除两侧字符

- **机制**：它不是“删除单词”，而是“**像剥洋葱一样从外往里删**”。只要两侧的字符在参数字符串里，就会被删掉，直到遇到一个不在参数里的字符为止 。

```python
# 这里的参数是 'gaf'，表示遇到 g、a、f 任意一个都删
'aabbccddeeeffg'.strip('gaf')
# 右边：'g' 在 'gaf' 里 -> 删；'f' 在 -> 删；'f' -> 删；'e' 不在 -> 停。
# 左边：'a' 在 -> 删...
# 结果：'bbccddeee' [cite: 533-534]
```

##### 4）`find()` vs `index()`

- **区别**：找不到子串时，`find()` 返回 **-1**（安全），`index()` 抛出 **ValueError**（程序崩溃）

##### 5）`replace()` 替换

- `s.replace(old, new, count)`：`count` 控制替换次数，默认是全部替换 。
- 常用于**敏感词过滤**：把敏感词替换为 `***`

### 第八章：正则表达式

> 什么是正则表达式？
>
> **就是一个“超级通配符”，不找出具体的字，只找符合某种特征的字**

#### 一、核心语法

​	这部分是基础，考试常考写出匹配特定规则的正则表达式。

##### 1）元字符

​	这些字符有特殊含义，不再表示字符本身

- **`.` (点)**：匹配除换行符以外的任意字符（如果在 `re.S` 模式下也能匹配换行符）。
- **`^` 和 `$`**：匹配字符串的**开头**和**结尾** 。
  - 例：`^http` (必须以 http 开头) 。
- **`[]` (字符集)**：匹配方括号内的**任意一个**字符。
  - `[abc]`：匹配 a 或 b 或 c。
  - `[^abc]`：匹配**除了** a、b、c 之外的字符（取反）。
  - `[a-z]`：匹配范围 。
- **`|` (或)**：匹配左边或右边的模式。
  - 例：`python|perl`

##### 2）预定义字符集

- **`\d`**：数字 (相当于 `[0-9]`) 。

- **`\w`**：匹配**字母、数字、下划线、汉字** 。
  - *注意*：在 Python 3 中 `\w` 包含汉字，这和很多其他语言不同。

- **`\s`**：匹配空白字符（空格、换行 `\n`、制表符 `\t` 等）。

- **大写形式 (`\D`, `\W`, `\S`)**：表示对应小写形式的**反义**（例如 `\D` 匹配非数字）。
- **`\b`**：匹配单词边界 (Word Boundary)。
  - *考点*：它不匹配任何字符，只匹配位置（如单词和空格之间）。
  - *陷阱*：Python 字符串中 `\b` 是退格符，正则中是边界，所以**必须使用原始字符串 `r''`**，如 `r'\bclass\b'` 。

##### 3）量词——控制出现次数

- **`\*`**：0次或多次 。
- **`+`**：1次或多次 。
- **`?`**：0次或1次 。
- **`{m,n}`**：m 到 n 次 。

#### 二、`re`模块常用函数

| **函数**           | **功能**                   | **返回值**        | **备注**                      |
| ------------------ | -------------------------- | ----------------- | ----------------------------- |
| **`re.match()`**   | 从字符串**起始位置**匹配   | Match对象 或 None | 如果开头不匹配，直接失败      |
| **`re.search()`**  | 扫描**整个字符串**查找匹配 | Match对象 或 None | 只要找到一个就返回            |
| **`re.findall()`** | 查找**所有**匹配项         | **列表 (List)**   | 返回所有匹配到的字符串列表 。 |
| **`re.split()`**   | 根据正则切割字符串         | 列表              | 比字符串的 `split` 更强大 。  |
| **`re.sub()`**     | 替换匹配项                 | 字符串            | 类似 Word 的“全部替换” 。     |

- **Match看开头，Search搜所有**：Match 必须从头配，Search 全文找。
- **Findall 有坑**：遇到括号 `()` 只返回括号里的内容，没括号才返回全部。
- **问号是关键**：`*?`、`+?` 是非贪心（找到最短的就停），不加问号是贪心（一直吃到死）。
- **边界要加r**：用到 `\b` (边界) 或 `\` (转义) 时，字符串前必须加 `r`，如 `r'\d+'`。
- **Sub 能变身**：`re.sub` 的第二个参数可以用 lambda 函数，实现动态替换（如转大写）。
