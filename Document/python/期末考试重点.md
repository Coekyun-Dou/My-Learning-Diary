##### 1）常量与变量

- 使用前无需声明变量以及类型
- python中变量**不直接存储值，而是存储值的内存地址或引用**，如果不同变量赋值为相同值，这个值在内存中只有一份，**多个变量会同时指向一块内存地址**。
- 因为python属于**强类型编程语言**python不仅变量的值是可以变化的，类型也是可以随时变化的

- python的命名规则
  - 必须以字母、汉字或下划线开头
  - 不能包含空格或中英文标点符号
  - 不能使用关键字，不建议使用系统内置模块名
  - 对英文字母大小写敏感

##### 2）数字

- Python支持**任意大**的数字，具体多大受内存大小限制

- 由于精度问题，**要尽量避免在实数之间直接进行相等性测试**

  - ```python
    0.4 - 0.3 == 0.1 #结果是False
    ```

  - 如何解决这个问题？使用**decimal类型**、或者用math.isclose函数

  - ```python
    from decimal import Decimal
    a = Decimal('0.1')
    b = Decimal('0.2')
    a + b == 0.3
    ```

##### 3）字符串与字节串

- Python中只有字符串没有字符的概念，**单个字符也是字符串**，使用**单引号、双引号、三单引号、三双引号**作为定界符来表示字符串，**不同的定界符之间可以互相嵌套**

### 第三章：Python可迭代对象

#### 一、列表

​	包含若干元素、连续内存空间；能够自动管理内存，比如在中间删去一个元素，那么后面的元素会自动补上来，保证相邻元素间没有缝隙。

​	列表间的元素用逗号隔开，同一个列表中元素的数据类型可以不同。

##### 1）列表的创建与删除

==**创建**==

- 直接创建

```python
a_list = ['a','b']
```

- 用list函数把其他可迭代对象转换为列表

```python
list(range(1,10,2)) #把range对象转换为列表
#结果为[1,3,5,7,9]
```

==删除==

- 使用del命令

```python
x = [1,2,3]
del x
```

##### 2）列表元素访问

- 可以使用下标来访问，**正序从0开始表示第一个元素，倒序从-1开始表示最后一个元素**，以此类推

##### 3）常用方法

- 插入操作

  - `append()`：在列表末尾追加一个元素

  - `insert(a,b)`：在a位置，插入元素b

  - `extend()`：用于将一个可迭代对象插入到列表尾部

- 删除操作
  - `pop()`：删除最后一个位置的元素
  - `remove(2)`：删除列表中第一个值为2的元素
  - `clear()`：清空列表中的所有元素
- 统计操作
  - `count(2)`：返回列表中出现2的次数
  - `index(2)`：返回元素2在列表中首次出现的位置
- 排序
  - `x.sort()`：按照默认规则排序
  - `x.reverse()`：把所有元素翻转或逆序

- 复制

  - 浅复制`copy()`：例如`y = x.copy()`，但是这样的话修改x的值会顺便改变y
  - 深复制`deepcopy()`：这样x和y完全独立，但是要先`import copy`

- 运算符

  - +表示连接左右的元素
  - 和整数相乘，表示重复序列
  - in 看看有没有包含某个元素
  - is 看相不相同

- 切片操作（用一个中括号表示）

  - 第一个数字表示切片开始位置，第二个数字表示切片截止位置，第三个数字表示切片步长

  - 切片开始坐标是从0开始，结束的坐标是从1开始（对于结束来说，列表的第一个元素坐标为1）

  - ```python
    aList = [3,4,5,6,7,9,11,13,15,17]
    aList[1,3] #从1开始，到3结束（对应下标3-1=2）
    >>> 4,5
    aList[1::2] #从1开始，隔一个取一个获取奇数位置的元素
    >>> 4,6,9,13,17
    ```

  - 还可以用切片在列表任意位置插入新的元素

  - ```python
    aList[len(aList):] = [9] #在列表尾部增加元素
    aList[:0] = [1,2] #在列表头部插入多个元素
    aList[3:3] = [4] #在列表中间位置插入元素
    ```

#### 二、元组

​	放在一对圆括号里，元素之间用逗号隔开，**如果元组只有一个元素则必须在最后加一个逗号**，（真正创建元组的是逗号，圆括号只是辅助）定义后的**元组中元素的数量和引用不允许改变**，这是元组与列表最本质的区别。

##### 1）元组的创建与访问

```python
x = (1,2,3) #元组的创建
x[0] #元组通过下标访问，结果是1
x[-1] #最后一个元素，同样支持双向索引
```

##### 2）与列表的异同

- 都是有序序列，可以双向索引，都支持切片操作
- 元组不可更改，所以没有插入、删除操作，也不知通过切片来修改元素

#### 三、字典

​	字典是一个包含若干**键值对**的**无序可变容器对象**，字典中**每个元素用冒号分隔开“键”与“值”两部分**（键与值用冒号隔开，键值对与键值对用逗号隔开），最后所有的元素放在一对大括号里面。

​	字典中的**键得是不可变的数据**，如整数、实数、复数、字符串等，不能用列表、集合等其他可变类型对象。**字典中的键不允许重复，但是值允许**

##### 1）字典的创建与删除

```python
data = {'国家':['富强','民主','文明','和谐'],
		'社会':['自由','平等','公正','法治'],
		'公民':['爱国','敬业','诚信','友善']}
```

##### 2）字典元素的访问

​	通过输入字典的键，来访问对应的值。

```python
aDict['aget'] #会输出age键对应的值
```

##### 3）字典元素的添加、修改与删除

- 添加与修改

  - 当指定的键存在时，表示修改该键对应的值；

  - 当指定的键不存在时，表示添加一个新的“键、值”，也就是添加一个新的元素。

  - ```python
    aDict['age'] = 39 #修改age对应的值为39
    aDict['address'] = GDOU #没有address这个键，相当于添加新元素
    ```

  - `	update()`方法用于把另一个字典的键值对添加到当前字典对象中，如果存在相同的键，则以update更新的为准。

- 删除操作
  - 使用del命令，例如：`del aDict['age']`删除字典中age这个键所在的元素
  - `pop()`：删除指定的“键”，返回对应的“值”
  - `popitem()`：删除最后一个元素，并返回

#### 四、集合

​	集合属于无序可变容器对象，由一对大括号围住，元素之间使用逗号分隔，同一个集合内的每个元素都是唯一的，**元素之间不可以重复**。集合中只能包括不可变类型的数据，不可以包括列表、字典、集合等可变类型的数据。

##### 1）集合的创建与删除

- 直接创建

  - ```py
    a = {1,2,3}
    ```

- 用set函数将列表、元组等转成集合，并自动去除重复元素。

  - ```python
    list = [0,1,1,2,3,4,3,3,4]
    b_set = ste(list) #结果是[0,1,2,3,4]
    ```

##### 2）集合元素的增加与删除

- 增加：`add()`方法：直接在集合内添加元素，如果元素已存在则忽略该操作。
- 修改：`update()`：用于合并另外一个集合中的元素到当前集合中，并自动去除重复元素
- 删除：
  - `pop()`随机删除集合中一个元素，集合如果为空抛出异常
  - `remove()`删除集合中的指定元素，如果不存在则抛出异常
  - `discard()`用于从集合中删除一个特定元素，如果不在则忽略该操作
  - `clear()`清空集合删除所有元素

##### 3）集合的操作与运算

```py
a_set | b_set  # 并集
a_set.union(b_set) #并集
a_set & b_set  #交集
a_set.intersection(b_set) #交集
a_set.difference(b_set) #差集
a_set - b_set #差集
x < y #真子集
x <= y #子集
```

#### 三、循环结构

##### 1）for循环（一般用于循环次数确定）

```python
for 循环变量 in 可迭代对象：
	循环体
else：
	else子句代码
```

例子：

```python
#输出1~100之间能被9整除但不能同时被5整除的所有整数
for i in range（1，101）:
    if i%7==0 and i%5!=0:
        print(i)

#使用循环结构打印九九乘法表        
for i in range(1,10):
    for j in range(1,i+1):
        print('{0}*{1}={2}'.format(i,j,i*j),end='')
    print()
```

##### 2）while循环

```python
while 条件表达式：
	循环体
else：
	else子句
```

##### 3）break与continue语句

- break：使得break语句**所属层次的循环提前结束（不再循环）**
- continue：使得本次循环提前结束，忽略continue之后的所有语句，**提前进行下一次循环。**

```python
#计算小于100的最大素数
for n in range(100,1,-1):
    if n%2 == 0:
        continue
    for i in range(3,int(n**0.5)+1,2):
        if n%i==0:
            #结束内循环
            break
    else:
        print(n)
        #结束外循环
        break
```
