### 第一章：Python开发环境搭建雨使用

> 就考察两个东西：一个是pip，一个是库导入

#### 一、扩展库的安装

```
pip download // 下载扩展库
pip freeze[reqirements.txt] //列出已经安装的模块到requirements中
pip list //列出已安装的所有模块
pip install 安装
pip install xxx.whl //通过whl文件离线安装
```

#### 二、扩展库的导入与使用

- import 包名/模块名 [as 别名]

```python
import numpy as np
```

- from 包名/模块名 import 对象名 [as别名]

```python
from math import sin as f
```

- from 模块名 import *

```python
from math import * //一下导入模块中的所有对象
```

#### 三、`_name_`属性的使用

```python
def main()
	if _name_ == '_main_':
        print("Yes")
main()        
```
