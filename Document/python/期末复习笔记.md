### 1.2Python编程规范

#### 1）缩进

- 选择结构、循环结构、异常处理结构、with块、函数/方法定义、类定义，**行尾的冒号表示缩进的开始**
- Python依靠缩进来体现代码间的逻辑，**缩进结束表示一个代码块结束**
- 同一个级别的代码块缩进量必须相同

#### 2）导入模块

- 每个import语句只导入一个模块，最好按**标准库>>>扩展库>>>自定义库**的顺序依次导入。
- 建议只导入确实用到的对象，不建议把整个模块或库都导入

#### 3）注释

​	用#表示本行代码进行注释、或者是**三个引号**'''...'''、或“”“...."""进行注释

#### 4）开发速度与运行速度之间的平衡

​	由于**内置对象运行速度最快**，标准库对象次之，所以我们在开发项目时，要优先**使用python内置对象**，其次考虑python标准库提供的对象，最后考虑使用第三方扩展库。

#### 5）选择合适数据类型

- 如果定义一些数据只是用来频繁遍历并且关心顺序，最好**优先考虑元组**
- 如果要频繁地测试一个元素是否存在于一个序列中并且不关心其顺序，**尽量采用集合**
- **列表和元组的in操作的时间复杂度是线性的，而对于集合和字典却是常数级的**，与问题规模几乎无关。

### 1.5 _ name _ 属性的作用

​	每一个python文件都可以作为一个单独的脚本运行，也可以作为一个模块供其他脚本引入。_name _ 变量就是用来判断当前是哪一种情况，**只有当name变量 == main的时候，程序才会执行；否则系统就是认为当前脚本是作为模块导入的，所以不会运行**。

- 如果脚本作为模块被导入，name的值自动设置为模块名
- 如果脚本独立运行，name的值自动被设置为 _ main _

```python
if _name_ == '_main_':
    ... #此处是要执行的语句
```

#### 1）常量与变量

- Python中**不需要事先声明变量名及其类型**
- 赋值的执行过程：把等号右侧表达式的值计算出来，在内存中找一个位置把值存进去，最后创建变量并指向这个内存地址。

- id()函数用来查看对象的内存地址

#### 1）算术运算符

- ==+运算符==除了用于算术加法以外，还可以用于**列表、元组、字符串的连接**，但不支持不同类型的对象之间的相加或连接

- ==*运算符==除了表示算术乘法，还可**用于列表、元组、字符串这几个序列类型与整数的乘法**，表示序列元素的重复，生成新的序列对象。**字典和集合不支持与证书的相乘**，因为其中的元素是不允许重复的。

  - ```python

- ==**运算符/和//**==在python中分别表示算术除法和<u>算术求整熵</u>（就是整除，去掉余数）

    3/2 #除法、结果是1.5

    ```

- **==%运算符==**可以用于整数或实数的求余数运算，还可以用于字符串格式化，但是这种用法并不推荐。

  - ```python
    '%c,%d,%f,%s' %(65,65,65,65)

- ==**运算符==可以表示幂乘，例如3**2 == 9

#### 2）成员测试运算符in与同一性测试运算符is

- 同一性测试==运算符is==，用来测试两个对象是否是同一个，如果是则返回true，否则返回false。**如果两个对象是同一个，二者具有相同的内存地址**。

  - ```python
    #注意！

    y = [1,2,3]
    x is y
    #结果是false 因为上面形式创建的x和y不是同一个列表对象
    ```

- **位运算符只能用于整数**，其内部执行过程为：首先将整数转换为二进制数，然后右对齐，必要的时候左侧补0至相同长度，按位进行运算，最后再把计算结果转换为十进制数字返回。

- 集合的交集、并集、对称差集等借助于位运算符来实现，而差集使用减号运算符来实现。

#### 4）逻辑运算符

- 逻辑运算符and、or、not常用来连接多个条件表达式构成更加复杂的条件表达式，并且and和or具有**惰性求值和逻辑短路**的特点，当连接多个表达式时**只计算必须要计算的值**
  - 例：表达式“exp1 and exp2”等价于“exp1 if not exp1 else exp2”，而表达式“exp1 or exp2”则等价于“exp1 if exp1 else exp2”
  - 在编写复杂条件表达式时充分利用这个特点，**合理安排不同条件的先后顺序，在一定程度上可以提高代码运行速度**
  - 另外要注意的是，**运算符 and 和 or 并不一定会返回True或False，而是得到最后一个被计算的表达式的值**，但是运算符**not一定会返回True或False**

#### 5）补充说明

- Python还有赋值分隔符 = 和 +=、-=、*=、/=、//=、**= 、 |=、^=等大量符合赋值分隔符。例如x+=3 等价于 x = x+3

- Python**不支持++和--运算符**，虽然在形式上有时候似乎可以这样用，但实际上是另外的函数；++1= 1 、--1=1（这里的 + 和 - 表示的是符号）

- ==**：=**海象运算符==，可以在选择结构、循环结构的条件表达式或者函数调用中直接创建变量并为变量赋值，使得代码更加简洁。这个运算符**不能在普通语句中直接使用，需要在外面加一对圆括号**
  
  - ```python
    #不使用海象运算符
    n = len(a_list)
    while n > 0:
        #do something(循环体)
        n -= 1
        
    #使用海象运算符
    while(n := len(a_list)) > 0:
        #do something(循环体)
    ```

## 第3章：Python可迭代对象

> 主要对列表、元组、字典、集合进行了相关的说明和解释

- 从面向对象程序设计的角度来看，实现了特殊方法`_iter_()`的类的对象称作**可迭代对象**，同时实现了`_iter_()`和`_next_()`的类的对象称作**迭代器对象**
- 可迭代对象包括迭代器对象以及列表、元组、字典、集合、字符串和range对象。其中，列表、元组、字典、集合、字符串这几种类型的对象在任何时刻都在相应的内存中包含了全部的元素，称为**容易对象**
- **range对象**比较特殊，不在内存中包含具体的元素但支持下标和切片运算，没有实现特殊方法`_next_()`所以又不属于迭代器对象。（所以是可迭代对象）
- **迭代器对象**具有惰性求值的特点，只在必要时才会生成下一个值。迭代器对象不持有任何元素，不适用下标和切片访问指定位置上的元素，也不支持切片运算和内置函数`len()`，只能从前往后逐个生成值。

### 3.1 列表

- 列表是**包含若干元素的有序连续内存空间。当列表增加或删除元素时，列表对象自动进行内存的扩展或收缩**，保证相邻元素之间没有缝隙。**插入和删除非尾部元素涉及到列表中大量元素的移动**会影响效率。所以要尽量从列表尾部进行元素的追加和删除。
- 在Python中，**同一个列表中元素的数据类型可以各不相同**，例如[10,'ten',[10,20]]

#### 1）列表创建与删除

- **创建**

> 可用中括号[]、以及list()函数来表示列表

```python
a_list = [1,2,3,4,5]
a_list = [] #创建空列表
#还可以使用list()函数把元组、range对象、字符串、字典等可迭代对象转换成列表
list((3,4,5,6))
list(range(1,10,2))
list('hello world')
list({3,4,5})
x = list() #创建空列表
```

- 删除：当一个变量不再使用时，可以使用del命令将其删除

```python
x = [1,2,3]
del x
x #会显示异常：name 'x' is not defined
```

#### 2）列表元素访问

​	创建列表之后，可以用下标来访问其中的元素，**0表示第一个元素，以此类推**，而且支持负整数作为下标，**-1表示最后1个元素，以此类推**。

```python
x = list('python')
print(x[0]) #结果是p
print(x[-1]) #结果是n
```

#### 3）列表常用方法

##### 1、append()、insert()、extend()

- append()用于向列表尾部追加一个元素
- insert()用于向列表任意指定位置插入一个元素
- extend()用于将参数可迭代对象中的所有元素追加至当前列表的尾部

```python
x = [1,2,3]
x.append(4)
x.insert(0,0)
x.extend([5,6,7])
x #结果是[0,1,2,3,4,5,6,7]
```

##### 2、pop()、remove()、clear()、del命令

> 这4个方法也属于**原地操作**

- pop()用于删除并返回指定位置（默认是最后一个）上的元素；
- remove()用于删除列表中第一个值与指定值相等的元素
- clear()用于清空列表中的所有元素
- del命令用于删除列表中指定位置的元素

```python
x = [1,2,3,4,5,6,7]
x.pop() #结果是7
x.pop(0) #结果是1
x.clear() #结果是[]
x = [1,2,1,1,2]
x.remove(2) #删除首个值为2的元素 结果为[1,1,1,2]
del x[3] #结果为[1,1,1]
```

##### 3、count()、index()

- count()用于返回列表中指定元素出现的次数
- index()用于返回指定元素在列表中**首次出现的位置**，如果该元素不在列表中则抛出异常

```python
x = [1,2,2,3,3,3,4,4,4,4]
x.count(3) #结果是3
x.count(5) #不存在，返回0
x.index(2) #首次出现的位置为x[1]
x.index(5) #没有该元素，报错
```

##### 4、sort()、reverse()

- sort()用于按照指定规则对所有元素进行排序
- reverse()用于将列表所有元素逆序或翻转

##### 5、copy()

- copy()返回当前列表的浅复制，返回包含原列表中所有元素的引用的新列表

<img src="C:\Users\Duuuzx\AppData\Roaming\Typora\typora-user-images\image-20251029202008963.png" alt="image-20251029202008963" style="zoom:60%;" />

> Python中，浅复制是对象复制的一种方式，它创建了一个新的复合对象，然后（将原始对象中的）每个元素（子对象）的引用插入到这个新对象中。**这意味着原始对象和新对象共享对子对象的引用，而不是子对象本身的副本**。因此，**如果子对象是可变的（如列表、字典等），那么对子对象的修改将同时影响原始对象和新对象中的对应部分**

- 标准库copy中的deepcopy()函数可以实现**深复制**，对原列表中的元素的引用进行复制，如果元素是容器对象就递归对其中的元素进行复制。**深复制得到的对象与原来的对象完全独立**
