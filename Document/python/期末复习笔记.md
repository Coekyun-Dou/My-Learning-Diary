- 跨平台、开源、免费的**解释型高级动态编程语言**
- 支持**命令式编程**（How to do）、**函数式编程**（What to do），完全支持面向对象程序设计，拥有大量**扩展库**

- 常用打包工具：pyinstaller、cx_Freeze、py2app、Nuitka

### 1.2Python编程规范

#### 1）缩进

- 选择结构、循环结构、异常处理结构、with块、函数/方法定义、类定义，**行尾的冒号表示缩进的开始**
- Python依靠缩进来体现代码间的逻辑，**缩进结束表示一个代码块结束**
- 同一个级别的代码块缩进量必须相同

#### 2）导入模块

- 每个import语句只导入一个模块，最好按**标准库>>>扩展库>>>自定义库**的顺序依次导入。
- 建议只导入确实用到的对象，不建议把整个模块或库都导入

#### 3）注释

​	用#表示本行代码进行注释、或者是**三个引号**'''...'''、或“”“...."""进行注释

#### 4）开发速度与运行速度之间的平衡

​	由于**内置对象运行速度最快**，标准库对象次之，所以我们在开发项目时，要优先**使用python内置对象**，其次考虑python标准库提供的对象，最后考虑使用第三方扩展库。

#### 5）选择合适数据类型

- 如果定义一些数据只是用来频繁遍历并且关心顺序，最好**优先考虑元组**
- 如果要频繁地测试一个元素是否存在于一个序列中并且不关心其顺序，**尽量采用集合**
- **列表和元组的in操作的时间复杂度是线性的，而对于集合和字典却是常数级的**，与问题规模几乎无关。

### 1.4 标准库与扩展库对象的导入与使用

```python
# 主要有以下几种导入格式：
# 1、import 包名/模块名 [as 别名]

# 2、from 包/模块 import 模块/对象[as 别名]
from math import sin

# 3、from 包/模块 import * (全部引入)

```

### 1.5 _ name _ 属性的作用

​	每一个python文件都可以作为一个单独的脚本运行，也可以作为一个模块供其他脚本引入。_name _ 变量就是用来判断当前是哪一种情况，**只有当name变量 == main的时候，程序才会执行；否则系统就是认为当前脚本是作为模块导入的，所以不会运行**。

- 如果脚本作为模块被导入，name的值自动设置为模块名
- 如果脚本独立运行，name的值自动被设置为 _ main _

```python
if _name_ == '_main_':
    ... #此处是要执行的语句
```

#### 1）常量与变量

- Python中**不需要事先声明变量名及其类型**
- 赋值的执行过程：把等号右侧表达式的值计算出来，在内存中找一个位置把值存进去，最后创建变量并指向这个内存地址。
- **python中的变量不直接存储值，而是存储了值的内存地址或者引用**
- id()函数用来查看对象的内存地址

```python
x = 3
id(x)
y = x
id(y)
x += 6
id(x)
```

- Python采用的是**基于值的内存管理方式**，如果不同变量赋值为相同值，这个值在内存中只有一份，**多个变量指向同一块内存地址**

<img align='left' src="C:\Users\Duuuzx\AppData\Roaming\Typora\typora-user-images\image-20251015094325102.png" alt="image-20251015094325102" style="zoom:80%;" />

- 交互模式下同一个语句中直接赋值的任意大整数变量具有相同的内存地址，但不适用于表达式。（直接赋值的时候赋多大值的地址都是相同的，但是表达式=太大就会不适用）
- Python是**强类型编程语言**，Python解释器会根据赋值或运算来自动**推断**变量类型。Python还是一种**动态类型语言**，变量的类型也是可以随时变化的。
- 定义变量名、函数名、类名、方法名等标识符时，要注意：
  - 必须以汉字、英文字母或下划线开头（但是下划线开头的变量再Python中的特殊含义）
  - 不能包含空格及标点
  - 不能使用关键字
  - 对英文字母**大小写敏感**
  - 不建议使用系统内置的模块名

#### 2）数字

- Python支持**任意大**的数字，具体多大受内存大小限制

- 由于精度问题，**要尽量避免在实数之间直接进行相等性测试**

  - 如何解决这个问题？使用**decimal类型**

  - ```python
    from decimal import Decimal
    a = Decimal('0.1')
    b = Decimal('0.3')
    a + b == 0.3
    ```

- 数字在运算中，会进行**隐式的类型转换**（有复数会转成复数计算，有小数会转成小数运算）

- Python3.6以上的版本支持在数字中间使用单个下划线对数字分组来提高可读性，类似数学上使用逗号作为千位分隔符

  - 单个下划线**可以出现在中间任意位置**
  - 但是**不能出现在开头和结尾，也不能使用多个连续下划线**

#### 3）字符串与字节串

- Python中只有字符串没有字符的概念，**单个字符也是字符串**，使用**单引号、双引号、三单引号、三双引号**作为定界符来表示字符串，**不同的定界符之间可以互相嵌套**
- 可以用 + 号连接字符串
- 对str类型的字符串调用其**encode()**方法进行编码德奥bytes字节串，对bytes字节串调用**decode()**方法并指定正确编码格式进行解码得到str字符串
