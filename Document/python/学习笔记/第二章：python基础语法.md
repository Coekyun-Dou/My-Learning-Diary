### 2.2 注释

#### 1、注释的作用

​	注释就是在程序代码中对程序代码进行解释说明的文字；

​	注释不会被执行、程序会跳过这一部分。

#### 2、注释的分类

- 单行注释：以 `#开头`  ，`#右边` 的所有文字当作说明，而不是真正要执行的程序，起**辅助说明作用**
  - python的规范中，#后要加一个空格（不加也不会影响运行）
  - 单行注释一般用于解释单行代码或一小段代码

```python
# 单行注释
print("hello world")
```

- 多行注释：以**一对三个双引号**引起来( """ 注释内容 """ )来解释说明一段代码的适用方法
  - 多行注释一般用于解释整个python代码文件、类或方法

```python
"""
	多行注释
	诗名：悯农
	作者：李绅
"""
print("锄禾日当午")
print("汗滴禾下土")
print("谁知盘中餐")
print("粒粒皆辛苦")
```

### 2.6 标识符

#### 1）什么是标识符

​	在python程序中，我们可以给很多东西起名字，比如：

- 变量的名字
- 方法的名字
- 类的名字，等等

​	这些名字，我们将它统一称之为标识符，用来做内容的标识；所以标识符就是：**用户在编程的时候所使用的一系列名字，用于给变量、类、方法等命名**

#### 2）标识符命名规则

​	python中，标识符命名的规则主要有3类

- 内容限定
  - 标识符的命名中，只允许出现`英文` `中文` `数字` `下划线_` 这四类元素，其余任何内容不被允许
  - 其余注意事项：**不推荐使用中文**、**数字是不可以用在开头**
- 大小写敏感
  - Andy != andy (能够区分大小写字母)
- 不可使用关键字
  - 例如and、as等等的关键字
  - 关键字也是有大小写敏感的，例如False是关键字，但是false就不是关键字

#### 3）变量命名规范

​	我们目前只接触到变量，还未接触到类、方法；所以我们先了解变量的命名规则

- 见名知意（明了、简洁）
- 下划线命名法（多个单词组合而成，用下划线做分割，如student_age）
- 英文字母全小写
