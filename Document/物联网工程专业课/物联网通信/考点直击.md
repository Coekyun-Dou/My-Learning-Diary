### 第一章：物联网通信概述

> 主要是物联网的三层结构

#### 一、基础概念

##### 1、物联网的构成

- 感知控制层（采集数据，并把数据发给网络传输层）
  - **数据采集子层**：传感器、RFID、NFC
  - **短距离通信传输子层**：蓝牙、Wi-Fi（把采集到的信息汇聚到网络传输层的信息传送系统）
  - **协同信息处理子层**：将采集到的信息进行汇聚处理，降低信息的冗杂。
- 网络传输层：将来自感知控制层的信息通过各种承载网传送到应用层。
- 应用层：最高层与用户交互
  - 服务支撑层：用于各种行业应用的信息服务平台。
  - 行业支撑层：面向各个方面的应用。
- 公共支撑层：为整个物联网安全保驾护航

##### 2、频谱扩展与分配

- 频谱分配：把不同功能的电磁波分到不同频率，避免干扰
- 频谱扩展：通过扩频技术，让信号可以在重叠的频段传输信息

##### 3、一些技术的工作频率：

- UWB的带宽频率：7.5GHz
- Wi-Fi的最高带宽：11MB

#### 二、简答题

##### ==1、简述什么是物联网，以及物联网的体系结构？==

​	物联网是物物相连的互联网，有两层意思，一是物联网的核心和基础仍然是互联网，所以是互联网基础上扩展和延申的网络；二是，物联网的用户端扩展到了任何物体与物体之间，实现了物物相息。

​	由三个层次构成：感知控制层、网络传输层与应用层；以及公共支撑层贯穿其中，保障整个物联网的安全。

##### 2、简述物联网感知控制层的通信网络类型

​	RFID、蓝牙、ZIgBee、IrDA红外连接技术，近距离无线通信NFC、Wi-Fi、超宽带技术UWB

##### 3、简述物联网网络传输层的网络类型

​	M2M技术、无线个域网（WPAN）、移动通信

### 第二章：通信原理

#### 一、基础概念

##### 1、消息与信息

- 消息：信息的载体、包含信息，是信息的外在形式
- 信息：消息的内涵，是有效信息，也是通信的传递的目的。

##### 2、信息量度量

- 信息量：$I=log_a{\frac{1}{P(x)}}=-log_a{P(x)}$（一般情况下，a=2，P(x)的消息x发生的概率）
- 性能指标——有效性
  - 码元传输速率：$R_B=\frac{1}{T}$，其中T为1个码元的持续时间。
  - 信息传输速率：$R_b=R_Blog_2M(b/s)$，M为进制数
  - 频带利用率（单位带宽内的传输速率）：$\eta=\frac{R_B}{B}$
- 性能指标——可靠性
  - 误码率：$P_e=\frac{错误的码元数}{传输的总码元数}$
  - 误信率：$P_b=\frac{错误的比特数}{传输的总比特数}$

#### 三、简答题

##### 1、通信的目的是什么？

​	为了传递消息中的信息。

##### 2、什么是信道？

​	消息发送需要经过一个数据通道，才能把数据传给对方，这个数据通道就是信道。

##### 3、通信系统的一般模型

​	由信息源、发送设备、信道、接收设备、受信者、噪声源几个部分构成的模型。

##### 4、模拟通信系统中，信息传递要经过哪两种变换？

- 模拟信号与原始电信号（基带信号）之间的变换
- 基带信号与带通信号之间的变换

##### 5、数字通信系统比模拟通信系统多了哪些部件，作用是什么？

- 发送端增加了信源编码、加密、信道编码部分；接收端加了信源译码、解密、信道译码部分
- 信源编码译码是进行数模转换，提高信息传输的有效性；加密解密是保障信息传输的安全；信道编码译码是提高抗干扰能力

##### 6、数字通信系统的性能指标有哪些？

- 有效性：用传输速率和频带利用率衡量
- 可靠性：用误码率和误信率衡量

    - **蓝牙无线收发器**：**蓝牙设备的核心**，用来调制/解调、帧定时恢复和跳频、同时完成发送和接收的功能。

    - **通用异步收发器**：通过无线信道接收或传输数据，并通过**主机控制接口HCI**接收要发送到主机系统以及来自主机系统的数据。
    - **链路管理协议**：负责两个或多个设备链路的建立和拆除及链路的安全和控制，包含报文、广播、数据通信的详细定义。为上层软件模块提供了不同的访问入口。
      - 定义了设备的5种状态：**就绪（核心状态）、扫描、广播、发送、连接**

- ==中间协议层（决定数据要怎么传）==

  - 中间协议层**工作在蓝牙的逻辑链路**上，为高层应用协议或程序提供了必要的支持，为上层应用提供了各种不同的标准接口
  - **串口仿真协议（RFCOMM）**：是一个仿真有线链路的无线数据仿真协议，提供了**对RS-232串行接口的仿真**，为建立在串口之上的传统应用提供接口环境。
  - 电话控制协议：面对比特流的协议，具有支持电话功能。包括电话控制协议、AT指令集和音频。
    - 两个蓝牙设备间提供最多60条连接，最大可以接收发送32KB大小的数据分组。
    - 在基带上处理音频信号，采用SCO链路传输语音。
  - 服务发现协议（SDP）
    - 服务发现协议是一个基于客户/服务器结构的协议，是为实现蓝牙设备之间相互查询及访问对方提供的服务，是蓝牙框架的一个重要组成部分。

- ==高端应用层（位于蓝牙协议堆栈之上的蓝牙应用程序以及所涉及的协议）==

  - 对象交换协议OBEX：支持设备间的数据交换，采用客户/服务器模式提供与HTTP相同的功能。
  - 因特网协议：用于实现蓝牙设备拨号上网，或通过网络接入点访问Internet和本地局域网
  - 无线应用协议WAP：支持移动电话浏览网页、收取点子邮件和其他基于因特网的协议。
  - 无线应用环境WAE：提供用于WAP电话和个人数字助理PDA所需的各种应用软件

#### 二、问答题

##### 1、蓝牙技术采用的主要协议是什么？

- 点对点协议（PPP）：通过点对点连接传输IP数据包
- TCP/IP/UDP：协议组的基础协议
- 对象交换协议（OBEX）：用于对象交换的会话层协议，为对象与操作表达提供模型；
- 无线应用环境/无线应用协议（WAE/WAP）：WAE明确了无线设备的应用框架，WAP是向移动用户提供电话和信息服务

##### 2、蓝牙技术的特点

​	全球范围适用；可以同时传输语音数据；可建立临时对等连接；可以实现近距离通信；功耗体积小；具有很好的抗干扰和安全性。

##### 3、简述蓝牙、ZigBee、Wi-Fi技术的主要差别

- 传输距离上：WiFi > ZigBee > 蓝牙
- 功耗上：WiFi > 蓝牙 > ZigBee（后两者电池供电）
- 传输速率上：WiFi > ZigBee > 蓝牙

##### 4、什么是微微网以及散射网？它们的作用分别是什么？

- 微微网：一种蓝牙连接的微型网络，首先提出通信要求的设备为主设备，被动进行的设备为从设备，一个主设备可以同时向7个从设备通信，可以和7个保持同步但不通信。
- 散射网：多个微微网在时空上相互重叠形成的比微微网覆盖范围更大的蓝牙网络，特点是微微网间有互联的蓝牙设备

##### 5、蓝牙技术的主要应用？

​	蓝牙耳机、手机、笔记本电脑、数字照相机、家电.....

##### 2、扩频技术

- 直接序列扩频（DS或DSSS）：发送端扩频、接收端解扩
- 跳频扩频技术（FH或FHSS）：随机变换传输频率，防止碰撞
- 正交频分技术（OFDM）：包括BPSK、QPSK、16-QAM、64QAM四种调制方式

##### 3、CSMA/CA原理

###### 1）工作原理

- 载波监听CS：发送数据之前，对信道媒体进行监听，看看有没有其他设备在传输信号
  - 物理载波监听LBT：通过物理层检测信道能量或信号特征判断信道是否忙碌
  - 虚拟载波监听NAV：通过解析MAC帧头部中的Duration字段，设置网络分配矢量，预知信道未来的占用时间。
- 多址访问MA：每个站点发送的数据，可以同时被多个站点接收
- 冲突避免CA：在数据发送之前，先发送一个准备信号RTS，等待接收设备返回以内需发送信号CTS。
- ACK确认：数据发送成功后，接收设备发送一个确认信号ACK，如果发送设备在规定时间内没有收到ACK则认为数据丢失，重新发送。

##### 4、MAC接入技术（DCF和PCF）

- 分布式协调功能DCF：属于**竞争接入方式**，工作在BSS和IBSS中，RTS/CTS解决隐藏站点问题；CSMA/CA（主动避免的方式来代替被动监听）
- 点协调功能PCF：属于**无竞争接入方式**，只工作在BSS中，优先级更高

##### 5、Wi-Fi组网及应用

- 站：WLAN中用作客户端，是具有网络接口的计算机设备
  - SA：无线局域网能覆盖的区域范围
  - BSA：基本服务区，是构成无线局域网的最小单位
  - BSS：在一个BSA内相互联系、相互通信的一组主机
  - ESS：多个BSA通过分布式系统连接起来，形成拓展服务区
- 无线网络接口：负责处理从总段用户设备到无线介质间的数字通信（无线网卡）

##### 6、无线接入点AP

​	是类似蜂窝结构的基站，是无线局域网的重要组成部分，常位于BSA的中心，固定不动。

#### 二、简答题

##### 1、WLAN技术的优势是什么？

- 灵活性强，终端设备可以在WLAN网络覆盖范围内任意放置和低速移动
- 部署成本低，省去终端设备综合布线的费用
- 扩展能力好，增加AP就可以增大容量和覆盖范围

- 采用扩频和加密技术，有较强的抗干扰性和网络保密性

##### 2、简述WLAN网络帧的种类和用途（MAC帧的种类与作用）

- 管理帧：与无线网络运作有关的帧，如无线设备的连接，身份认证等。

##### 3、简述Ad-Hoc网络的特点

- 无中心自组织
- 动态拓扑
- 带宽及终端能量受限
- 多跳路由
- 移动终端的自主性和局限性
- 安全性差，扩展性不强
- 存在单向的无线信道

##### 4、终端与AP的连接过程是什么？

- 扫描：打开终端上的WiFi设备，搜索到AP热点；
- 认证：通过终端输入密码认证其合法性
- 关联：终端与AP之间建立连接

##### 5、简述几种IEEE802.11n使用的技术

​	MIMO、ACK、MCS、SDM、帧聚合技术

### 第五章：NB-IoT和LoRa通信

#### 一、基础概念

##### 1、NB-IOT的构成

​	终端+云，模块内部集成信息收发设备，可以直接和基站通信，是基于LTE网络的改造

##### 2、NB-IoT的特点及技术细节

- 广覆盖：
  - 支持三种部署方式
    - 独立部署：利用现网的空闲频谱或者新的频谱进行部署
    - 保护频段部署：利用LTE边缘保护频段中未使用的带宽资源
    - 频段带内部署：占用LTE中一个物理资源块
  - 最大链路预算提升20dB（100倍）
  - 重复发送
- 低功耗（缺点是时延比较大）：
  - 两种低功耗模式
    - 功耗节省模式PSM：无数据收发的情况下，终端休眠，不接收下行数据。只有主动发送上行数据，才可接收IoT缓存的下行数据
    - 增强型非连续接收eDRX：间隔固定周期接收
  - 三种工作状态
    - 激活状态/连接状态
    - 空闲状态
    - 休眠状态
- 大连接：
- 低成本：
  - 现有LTE网络基础上改造升级，降低网络成本
  - 低速率、低时延、低功耗有助于降低终端硬件成本

##### 3、NB-IoT的组成

- 核心网EPC：提供全IP连接的承载网络
  - CP模式：上行数据从E-UTRAN传输至MME
  - UP模式：和传统数据一样，在无线承载上发送数据
- 基站：主要完成无线接入网和UE之间的通信和管理功能
- UE具体终端实体：核心网的关键控制节点

#### 二、简答题

##### 1、简述LoRa技术的优势

​	NB-IoT技术支持设备在广域网的蜂窝数据连接，基于授权频谱的运营，可直接部署于LTE网络，可降低部署成本和平滑升级。LoRa工作在非授权频谱，网络部署具有自主性，理论上可以根据需要在任何地方进行部署，自由度和安全方面LoRa更具优势。

bit r_flag = 0;     // 回复标志位

// 简洁的字符串发送函数
void SendStr(char *s) {
    while (*s) {
        SBUF = *s++;
        while (!TI); TI = 0;
    }
}

void main() {
    // TMOD: T1方式2(波特率), T0方式1(1s定时)
    TMOD = 0x21;  
    TH1 = 0xFD; TL1 = 0xFD; // 波特率9600
    TH0 = 0x4C; TL0 = 0x00; // 50ms定时初值
    
    TR1 = 1; TR0 = 1; // 启动定时器
    ES = 1; ET0 = 1; EA = 1; // 开启串口、T0、总中断
    SCON = 0x50;      // 串口方式1，允许接收

    while (1) {
        // 任务1：1秒发送
        if (s_flag) {
            s_flag = 0;
            SendStr("Hello IoT!\r\n");
            send_cnt++;
        }
        // 任务2：收到'R'回复
        if (r_flag) {
            r_flag = 0;
            SendStr("Count: ");
            // 简洁的数字转字符逻辑 (例如: 005)
            SBUF = send_cnt/100 + '0';     while(!TI); TI=0; // 百位
            SBUF = send_cnt%100/10 + '0';  while(!TI); TI=0; // 十位
            SBUF = send_cnt%10 + '0';      while(!TI); TI=0; // 个位
            SendStr("\r\n"); // 题目虽未明确要求换行，但为了美观通常加上
        }
    }
}

// 定时器0中断：产生1秒定时 (50ms * 20)
void Timer0_ISR() interrupt 1 {
    TH0 = 0x4C; TL0 = 0x00; // 重装初值
    if (++tick >= 20) {
        tick = 0;
        s_flag = 1;
    }
}

// 串口中断：接收处理
void UART_ISR() interrupt 4 {
    if (RI) {
        RI = 0; // 必清标志
        if (SBUF == 'R') r_flag = 1; // 仅当收到'R'时置位
    }
}
