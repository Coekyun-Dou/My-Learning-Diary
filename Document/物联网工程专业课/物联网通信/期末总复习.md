### 第一章：物联网通信概述

> 这一章主要都是一些基础概念，了解就好。

##### 1、物联网的定义

​	通过射频识别、红外感应等**信息传感设备**，按照**事先约定的数据传输协议**，把任何物品与互联网连接起来，以实现物之间的信息交换，从而实现智能化识别、定位、跟踪、监管和管理的一种网络。

​	物联网是继计算机、互联网与移动通信网之后的世界信息产业第三次浪潮。

##### 2、物联网内涵的两层意思

- 从领域的维度（横向）
  - **利用各种通信技术，使物==具有通信能力==**
  - **利用嵌入式等信息技术，使物有==信息处理能力*==**
- 从层次的维度（纵向）
  - 感知：实现全面感知
  - 传输：实现可靠传输
  - 智能：实现智能处理

##### 3、物联网的构成以及各层的功能作用

> 可以先记这一句话：三层构成：感知控制层，网络传输层，应用层，公共支撑层贯穿这三个层次。

- 感知控制层

  - 数据采集子层：传感器、RFID等
  - 短距离通信传输子层：**将局部范围内采集的信息汇聚到网络传输层的信息传送系统**
  - 协同信息处理子层：**将局部采集到的信息通过汇聚装置及协同处理系统进行数据汇聚处理**，以**降低信息的冗余度、提高信息的综合应用度，降低与传送网络层的通信负荷。**

- 网络传输层：将来自感知控制层的信息通过各种承载网传送到应用层。

- 应用层：最高层，应用的层面，与用户交互。

  - 服务支撑层：用于各种行业应用的信息服务平台。
  - 行业支撑层：面向各个方面的应用。

  <img align='left' src="C:\Users\Duuuzx\AppData\Roaming\Typora\typora-user-images\image-20251025175209064.png" alt="image-20251025175209064" style="zoom:80%;" />

- 还有一个**公共支撑层**，贯穿三个层次，为整个物联网安全、有效地运行提供保障。

##### 4、物联网通信系统感知层通信与核心承载网通信方面各自包括了哪些技术。

> 物联网的通信系统主要包括**感知层的通信**和**网络传输层的通信（接入+承载）**

- **感知层通信技术**
  - 负责将各种传感器的信息传送到信息汇聚系统，再传送到网络传输层。
  - 主要技术：**RFID、蓝牙、ZigBee、WiFi**、IrDA红外连接技术、NFC、UWB（超宽带）
- **核心承载网**（网络传输层的主力）
  - 负责将感知层收集到的数据进行长距离传输，送到云端或者服务器
  - 主要技术：**4G/5G移动通信网络、互联网（光纤通信、TCP/IP网络）、卫星通信**等

##### 5、物联网通信频谱扩展与分配问题

​	无线通信是利用**一定频段的电磁波**来传输信息的。理论上，**在一定区域范围内，传输电波的频段是不能重叠的**，如重叠则会形成电磁波干扰，从而**影响6通信质量**。于是采用频谱分配与扩展技术来解决上述问题：

- 频谱分配（规划车走哪条路）：按照不同的频率，将电磁波分成不同的功能，在一定频段内的电磁波用于特定的功能，保证电磁波之间互不干扰。
- 频谱扩展（怎么在拥堵的路上走得稳）：实现可以通过重叠的频段来传输信息，也就是通过扩频技术，让信号可以在干扰下传输；

### 第二章：通信原理

#### 一、基础概念

##### 1、消息与信息

- **消息**：是物质或精神状态的一种翻译，是信息的物质载体，也是信息的外在表现形式。
- **信息**：是消息的内涵，是消息中包含的有效信息。

​	==通信的目的就是：传递消息中所包含的信息==

##### 2、通信系统的一般模型，各个环节的作用。

​	通信系统是指：实现通信（信号的产生、发送、传输、接收和恢复）过程所需的一切**技术设备（包括信道）的总和**

###### 1、通信系统的一般模型

<img align='left' src="C:\Users\Duuuzx\AppData\Roaming\Typora\typora-user-images\image-20251027202622171.png" alt="image-20251027202622171" style="zoom: 60%;" />

> 信源和发送设备合称发送端
>
> 接收设备和受信者合称发送端

- ==信号源==：简称信源，**信源的任务就是把各种消息转换成原始电信号**
- ==发送设备：==对**信源进行处理，产生适合在信道中传输的信号**
- ==信道==：传输信息的**数据通道**，是一个物理媒介。根据物理媒介的不同，可以分为**有线信道**和**无线信道**
- 接收设备：从受到减损的接收信号中**正确恢复出原始电信号**的设备；具有**消息接收的功能，能够对消息内容进行一定的处理**
- 受信者：又称**信宿**，**把原始电信号还原成相应的消息**
- 噪声源：从电磁学的角度讲，干扰信号传输的能量场，称为噪声。这种能量场的产生源可以来自内部系统，也可以产生于外部环境。在通信系统中，**分布于各处的各种噪声源统称为噪声。**

###### 2、模拟通信系统与数字通信系统

> 根据信道中传输的信号类型不同，通信系统分为模拟通信系统和数字通信系统

1）模拟通信系统

2）数字通信系统

​	数字通信系统是利用数字信号来传递消息的通信系统；

- 发送端信道编码和译码的目的
  - 压缩编码提高信息传输的有效性
  - 完成模/数转换
- 接收端信道编码与译码的目的
  - 增强抗干扰能力，提高可靠性
- 加密与解密的目的：保证所传信息的安全
- 同步的目的：使收发两端的信号在时间上保持步调一致
- 数字调制与解调的目的：形成适合在信道中传输的带通信号
- 数字通信的优点
  - 抗干扰强、噪声不积累
  - 传输差错可控
  - 便于处理、变换、存储
- 数字通信的缺点
  - 需要较大的传输带宽
  - 对同步要求高

##### 3、模拟信号与数字信号

> 消息在信道中传输时，信号类型可以分为模拟信号和数字信号两种。

###### 1）模拟信号

​	**代表消息的信号参量取值连续**。例如麦克风输出电压。

​	通信系统中，连续的模拟信号必须先以适当的**频度**从中抽取其在各时刻的数值，形成相应的离散信号，然后进行处理。这个过程称为**抽样**

###### 2）数字信号

​	**数字信号代表消息的信号参量取值为有限个。**例如电报信号、计算机输入输出信号

- 码元：在数字通信中常常用时间间隔相同的符号来表示一个二进制数字。这种时间间隔内的信号称为（二进制）码元。这个间隔被称为码元长度。
- 数字信号在传输过程中不仅具有**较高的抗干扰性**，还可以通过**压缩，占用较少的带宽**，实现在相同的带宽内传输更多、更高音频、视频等数字信号的效果。

##### 4、通信系统的分类

###### 1、按通信业务分类

- 电报通信系统
- 电话通信系统
- 数据通信系统
- 图像通信系统

###### 2、按调制方式分类

- 基带传输系统：原始信号是基带信号
- 带通传输系统：带通信号是已调信号

###### 3、按信号特征分类

- 模拟通信系统
- 数字通信系统

###### 4、按照传输媒体分类

- 有线通信系统
- 无线通信系统

###### 5、按工作波段

- 长波通信：波长>100m
- 中波通信：1000m>波长>100m
- 短波通信：100m>波长>10m
- 微波通信：10m>波长>1mm（有**容量大、质量好，传播距离远**的特点）

###### 6、按信号复用方式分类

- 频分复用：不同信号占据不同频带
- 时分复用：不同信号占据不同时间片
- 码分复用：一组正交的脉冲序列分别携带不同的信号
- 波分复用：光纤通信中，在一条光纤内同时传输多个波长的光信号，提高光纤传输容量。

### 第三章：蓝牙通信

#### 一、基础概念

##### 1、蓝牙技术概述

​	蓝牙是一种**短距离无线通信技术**，具有**低成本、低功耗、组网简单和适于语音通信**等优点。

##### 2、蓝牙技术的特点

- 公开与共享（SIG成员就可以使用蓝牙最新技术）
- 短距离
- 无线性
- 具有互操作和兼容性（有标准规范，不同产品间相互兼容）
- 全球范围使用

  - 中间协议层**工作在蓝牙的逻辑链路**上，为高层应用协议或程序提供了必要的支持，为上层应用提供了各种不同的标准接口
  - **串口仿真协议（RFCOMM）**：是一个仿真有线链路的无线数据仿真协议，提供了**对RS-232串行接口的仿真**，为建立在串口之上的传统应用提供接口环境。
  - 电话控制协议：面对比特流的协议，具有支持电话功能。包括电话控制协议、AT指令集和音频。
    - 两个蓝牙设备间提供最多60条连接，最大可以接收发送32KB大小的数据分组。
    - 在基带上处理音频信号，采用SCO链路传输语音。
  - 服务发现协议（SDP）
    - 服务发现协议是一个基于客户/服务器结构的协议，是为实现蓝牙设备之间相互查询及访问对方提供的服务，是蓝牙框架的一个重要组成部分。

- ==高端应用层（位于蓝牙协议堆栈之上的蓝牙应用程序以及所涉及的协议）==

  - 对象交换协议OBEX：支持设备间的数据交换，采用客户/服务器模式提供与HTTP相同的功能。
  - 因特网协议：用于实现蓝牙设备拨号上网，或通过网络接入点访问Internet和本地局域网
  - 无线应用协议WAP：支持移动电话浏览网页、收取点子邮件和其他基于因特网的协议。
  - 无线应用环境WAE：提供用于WAP电话和个人数字助理PDA所需的各种应用软件

###### 2）工作原理

- 载波监听CS：发送数据之前，对信道媒体进行监听，看看有没有其他设备在传输信号
- 多址访问MA：每个站点发送的数据，可以同时被多个站点接收
- 冲突避免CA：在数据发送之前，先发送一个准备信号RTS，等待接收设备返回以内需发送信号CTS。
- ACK确认：数据发送成功后，接收设备发送一个确认信号ACK，如果发送设备在规定时间内没有收到ACK则认为数据丢失，重新发送。

###### 3）关键技术

- ACK确认：收到信息发送ACK给发送设备

- RTS/CTS机制：发送前发RTS，如果空闲就发CTS，接受到CTS再发信号

- 随机退避算法：当信道忙碌时随机等待一个时间段后再尝试，减少多个设备同时尝试发送数据的可能性，避免冲突

### 第八章：移动通信技术

```c
#include <reg52.h>

typedef unsigned int u16;
typedef unsigned char u8;

u16 tick = 0;       // 中断计数
u16 send_cnt = 0;   // 发送次数计数
bit s_flag = 0;     // 1秒标志位
bit r_flag = 0;     // 回复标志位

// 简洁的字符串发送函数
void SendStr(char *s) {
    while (*s) {
        SBUF = *s++;
        while (!TI); TI = 0;
    }
}

void main() {
    // TMOD: T1方式2(波特率), T0方式1(1s定时)
    TMOD = 0x21;  
    TH1 = 0xFD; TL1 = 0xFD; // 波特率9600
    TH0 = 0x4C; TL0 = 0x00; // 50ms定时初值
    
    TR1 = 1; TR0 = 1; // 启动定时器
    ES = 1; ET0 = 1; EA = 1; // 开启串口、T0、总中断
    SCON = 0x50;      // 串口方式1，允许接收

    while (1) {
        // 任务1：1秒发送
        if (s_flag) {
            s_flag = 0;
            SendStr("Hello IoT!\r\n");
            send_cnt++;
        }
        // 任务2：收到'R'回复
        if (r_flag) {
            r_flag = 0;
            SendStr("Count: ");
            // 简洁的数字转字符逻辑 (例如: 005)
            SBUF = send_cnt/100 + '0';     while(!TI); TI=0; // 百位
            SBUF = send_cnt%100/10 + '0';  while(!TI); TI=0; // 十位
            SBUF = send_cnt%10 + '0';      while(!TI); TI=0; // 个位
            SendStr("\r\n"); // 题目虽未明确要求换行，但为了美观通常加上
        }
    }
}

// 定时器0中断：产生1秒定时 (50ms * 20)
void Timer0_ISR() interrupt 1 {
    TH0 = 0x4C; TL0 = 0x00; // 重装初值
    if (++tick >= 20) {
        tick = 0;
        s_flag = 1;
    }
}

// 串口中断：接收处理
void UART_ISR() interrupt 4 {
    if (RI) {
        RI = 0; // 必清标志
        if (SBUF == 'R') r_flag = 1; // 仅当收到'R'时置位
    }
}
```
